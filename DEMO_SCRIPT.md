# RepoMindAI Demo Script

## 3 Minute Recruiter Demo

1. Open Executive Overview.
   - "RepoMindAI turns a repository into a scored engineering profile."
   - Point to Repository Health, Security Posture, Architecture Health, Investment Readiness.
2. Open Evidence Engine.
   - "Every score is explainable with weighted factors and source citations."
3. Open Reports.
   - "The product generates recruiter, CTO, due diligence, and executive reports from real analysis artifacts."

## 5 Minute CTO Demo

1. Start on Executive Overview.
   - Explain the 30-second readout: health, risk matrix, evidence docket, recommendation timeline.
2. Open Architecture Explorer.
   - Show request flows, generated sequence diagrams, architecture review, and AI architect findings.
3. Open Knowledge Graph.
   - Show domain/file/symbol/dependency/risk nodes, search, risk overlays, and focus drawer.
4. Open Security Center.
   - Show OWASP, CWE, CVSS, exploitability, business impact, and remediation steps.
5. Open PR Risk.
   - Paste changed files or a GitHub PR URL and show blast radius, affected services, reviewers, tests, and release gate.

## 10 Minute Investor Demo

1. Open Executive Overview.
   - "This is a CTO intelligence cockpit for acquisition and technical diligence."
2. Open Portfolio.
   - Show multi-repository dependency concentration, ownership map, bus factor, orphaned services, and single points of failure.
3. Open Drift.
   - Compare repository, branch, commit, or release snapshots.
   - Show service changes, dependency changes, external integration changes, API surface changes, and architecture drift timeline.
4. Open Due Diligence.
   - Show acquisition readiness, red flags, negotiation points, and memo views.
5. Open Reports.
   - Show investor-grade HTML/PDF/Markdown artifacts and the export bundle.
6. Open Chat.
   - Ask: "What are the top risks before acquisition?"
   - Show cited answer, source preview, related files, and follow-up prompts.

## Demo Close

RepoMindAI is not a generic coding assistant. It is a CTO intelligence platform for understanding architecture, risk, ownership, diligence readiness, and change impact across private repositories.
