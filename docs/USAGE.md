# Usage Guide

1. Start the backend and frontend.
2. Import a repository by ZIP upload, GitHub URL, or local path.
3. Select the repository and run analysis.
4. Review summary cards, architecture, security findings, and technical debt.
5. Ask questions in the AI Repository Q&A panel.
6. Download generated Markdown reports or export the report bundle.

Example questions:

- What does this project do?
- Where are API routes implemented?
- Which files are most important?
- What is missing for production readiness?
- Which files contain risky patterns?
